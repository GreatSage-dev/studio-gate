Execution Flow

Four steps. No ambiguity.

How StudioGate processes autonomous agent render requests, from dispatch to ledger.

01

Agent Dispatch

Autonomous VFX or Lighting agent requests a render job with projected GPU cost attached.

02

ClickHouse Query

FastAPI queries ClickHouse Cloud for the exact 1-hour rolling burn across all active studio nodes.

03

Policy Evaluation

Deterministic arithmetic: projected sum versus hard budget threshold. No model inference.

04

Ledger & Remediation

Result logged to SHA-256 chain. If blocked, Gemini generates cost-saving alternatives.
